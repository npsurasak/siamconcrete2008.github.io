# รูปภาพที่ต้องใส่ (วางไฟล์ในโฟลเดอร์นี้)

## 📸 วิธีเพิ่มรูปแกลเลอรีผ่าน GitHub (ไม่ต้องแก้โค้ด)

หน้าแกลเลอรีตรวจหารูปตามชื่อไฟล์เองอัตโนมัติ ขั้นตอนเพิ่มรูป:

1. เปิด repo ของเว็บบน **github.com** → เข้าโฟลเดอร์ `img`
2. กด **Add file → Upload files**
3. ลากรูปที่ตั้งชื่อตามกติกาด้านล่างลงไป แล้วกด **Commit changes**
4. รอประมาณ 1 นาที (GitHub Pages อัปเดตเอง) → รูปโผล่บนเว็บทันที

กติกาชื่อไฟล์ (ต้องเป็น **.jpg** เรียงเลข เริ่มจาก 1 สูงสุด 12 รูปต่อกลุ่ม — เว้นเลขได้):

| กลุ่ม | ชื่อไฟล์ |
|---|---|
| ภาพการจัดส่ง | `gallery-delivery-1.jpg`, `gallery-delivery-2.jpg`, … |
| ภาพหน้างานลูกค้า | `gallery-site-1.jpg`, `gallery-site-2.jpg`, … |
| ภาพสินค้าจริง (ต่อจาก 4 รูปเดิม) | `gallery-products-1.jpg`, `gallery-products-2.jpg`, … |

- รูปถูกครอปให้ช่องเท่ากันอัตโนมัติ (ไม่บี้ ไม่เบี้ยว) กดที่รูปเปิดดูเต็มใบได้
- แนะนำย่อรูปให้เหลือ ≤ 500 KB ก่อนอัป (มือถือใช้แชร์แบบ "ลดขนาด" ได้) เว็บจะได้โหลดไว
- ลบรูปออกจากโฟลเดอร์ = รูปหายจากเว็บเอง

**✅ โปสเตอร์สินค้า 7 หมวดใส่แล้ว** (`poster-1-cement.jpg` … `poster-7-tools.jpg`
แสดงเต็มในหน้า products.html) — ไฟล์ PNG ต้นฉบับเก็บไว้ที่ `..\..\poster-originals\`
ถ้าจะเปลี่ยนโปสเตอร์หมวดไหน วางไฟล์ใหม่ทับชื่อเดิมได้เลย

**รูปหลักของเว็บใช้ภาพครอปจากโปสเตอร์แบรนด์แล้ว**:
- `thumb-*.jpg` — รูปการ์ดหมวดสินค้า (หน้าแรก/โปรโมชั่น/แกลเลอรี) ครอปจากโปสเตอร์
- `hero-main.jpg` — รูปใหญ่หน้าแรก (คลังปูนจากโปสเตอร์) — ถ้ามีรูปถ่ายหน้าร้านจริง
  วางเป็น `hero.jpg` แล้วแก้ `src` ในหน้า index.html จุดเดียว
- `cat-*.svg` — ภาพวาดชุดเก่า ไม่ได้ใช้แล้ว (ลบได้)

จุดที่ยังรอรูปถ่ายจริงอย่างเดียว: แกลเลอรี "ภาพการจัดส่ง" และ "ภาพหน้างานลูกค้า",
แบนเนอร์หน้าโปรโมชั่น, รูปร้านหน้าเกี่ยวกับเรา

**ที่มาของรูป:** ใช้รูปถ่ายสินค้าจริงที่หน้าร้าน หรือไฟล์ภาพสินค้าจากตัวแทนจำหน่าย/
เซลส์ของแต่ละแบรนด์ (ขอไฟล์ประชาสัมพันธ์จากแบรนด์ได้ — ห้ามดึงรูปจากเว็บอื่นมาใช้
โดยไม่ได้รับอนุญาต)

หมายเหตุ:
- og-image (รูปตอนแชร์ลิงก์) ยังชี้ไปที่ `assets/og-image.jpg` ของเว็บเดิม
  ถ้าย้ายโฮสต์ใหม่ทั้งหมด ให้คัดลอกไฟล์นั้นมาด้วย หรือแก้ URL ใน `<meta property="og:image">` ทุกหน้า
- บีบอัดรูปก่อนอัปโหลด (แนะนำ ≤ 300 KB ต่อรูป) เพื่อให้เว็บโหลดเร็ว
- ใส่ `alt` ภาษาไทยอธิบายรูปทุกครั้ง เช่น "ปูนซีเมนต์ SCG ช้างแดงในร้านสยามคอนกรีต 2008"
